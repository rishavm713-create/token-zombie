# TZ 2.0 Master Build Spec (draft, repo-mapped). Status: nothing below is built unless marked DONE.
Source: owner-pasted research 2026-11-24 (project-reported numbers are NOT TZ results). Licences must be re-checked per dependency before use.
Rule: `tz code`, `tz split`, `tzroute` only ADVISE today; P0 is a real executor. Build all of a batch, then test once (tz lock).

## Gates for every item
accept = one small test + honest EST/MEASURED label; dep = justify startup ms, memory, licence; keep advice separate from execution; fail-open.

## P0 (build first, in this order)
1. Executor `bin/tzagent.py` (new), `tz agent "<task>"`: minimal loop (model call, shell/file tools, step cap, token budget), idea from mini-SWE-agent (MIT, keep notice if code is reused). Model call via the `claude -p` CLI first (no new dep); provider interface so LiteLLM/OpenCode can plug in later. accept: fixture task in tests/ab/fixture passes with fake `tests/fake/claude.py`.
2. `tz code --run` in `bin/tzsplit.py`: runs `code_pipeline()` phases through the executor, one checkpoint per phase (`tzhandoff.checkpoint`). accept: phases run in order, stop on first failed test.
3. Worktrees `tzmore.worktree_cmd`: create/own/remove one worktree per task, file-ownership map to stop two agents touching one file. accept: two tasks, overlapping file is refused.
4. Event ledger: extend `tzdb.py` (SQLite) with agent events (task, phase, model, tokens, ms). accept: row per phase.
5. Search: `rg` backend when present, Python fallback (`tzfinder.py`, `tzout.search`). Repo map: DONE (`tz map`, 023964f). Next: tree-sitter for JS/TS in `tzcompress.py` (replace brace scan) as OPTIONAL dep.
6. Permissions/sandbox: `tzpolicy.py` rules gate executor tools (deny-by-default outside the worktree); container is optional later.

## P1
- Headroom adapter: benchmark against `tzout.py` on the same logs; adopt only transforms with net gain (`tz bench`).
- ACP adapter in `bin/adapters/` (check each adapter's licence).
- 3 roles only: architect, builder, independent reviewer (reuse agent field in `tzsplit.AGENT`); debugger on demand.
- Perf profiler: time startup/hook/db/search separately; targets (proposed, unmeasured): hook p95 <50 ms, simple CLI <150 ms. Lazy-import in `bin/tz` mods map.
- Evals: harbor / terminal-bench runner for a real A/B of tz on/off (extends `tzab.py`, `tests/ab/`). `tz xcheck` vs ccusage: DONE.
