      Token Zombie Studio is in private beta

      Open sign-up is not available yet. Prepare your request below and keep it for when access opens. Nothing is sent: no sign-up service is connected to this page.

      What do you want Studio for?

      Is Studio just a wrapper around Claude Code?

      Claude Code writes the code. Studio is the layer around it: project memory, research, requirements, plan, task order, budget, approvals, evidence, release and maintenance. How mature each of those is appears in the status matrix.

      Can I use it today?

      It is in private beta and under active development. Do not rely on it for production work yet: security hardening is in progress after an internal review found open issues.

      What does it cost?

      Pricing is not finalised. Claude access is not included: you use your own Claude account or plan.

      Where does my project live?

      The current build runs on your machine, with a local web dashboard. Content that Claude Code processes goes to Anthropic under your own account, and research reaches the web.

      How is it related to Token Zombie Core?

      Core is a separate, free, MIT-licensed tool for saving context in Claude Code. It works on its own and never depends on Studio. Studio can read information from it.
