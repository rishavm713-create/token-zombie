Private beta

You bring the idea.
Studio manages the journey.

Token Zombie Studio plans a project, runs the work through Claude Code, checks each step, and pauses for your approval before anything risky. It is early software, built in the open about its limits.

What the beta does today

Plan
Turns an idea into requirements, an architecture summary and an ordered task list.
Run
Executes tasks through Claude Code in dependency order, with a live log.
Verify
Each task can carry a check that must pass before it counts as done.
Approve
Deploys, deletes, spending and outbound messages wait for your approval.
Checkpoint
Every passing task is saved as its own git commit in your project.
Playbooks
Reusable rules per project type, improved only after a test.

Where it is going

  1. Idea, research, planning
  2. Design and development through Claude Code
  3. Testing and security review
  4. Deployment and launch
  5. Maintenance

Beta notice. Studio is not a replacement for Claude Code. It needs Claude Code installed and your own Claude access. It does not promise finished, production-ready software without your review. Features above are the early engine; browser inspection, deployment and launch automation are still being built.

Access

Early access is not open yet. Pricing is not set. It runs locally on your machine and your code stays with you.
