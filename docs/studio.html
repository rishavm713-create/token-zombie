How it works

A project record, not a chat.

Every project lives in its own folder with a spec, a task graph, a memory file and a run history. Claude Code does the work; Studio keeps the order, the checks and the receipts.

1

Plan

Your idea becomes requirements, an architecture summary and an ordered task list with dependencies.

2

Run

Tasks execute through Claude Code in dependency order, with a live log you can watch in the browser.

3

Verify

Each task can carry a check that must pass before it counts as done. Failures stay failures.

4

Approve

Deploys, deletes and outbound messages wait for a clear yes from you.

5

Checkpoint

Every passing task is its own git commit in your project, so you can roll back any step.

6

Playbooks

Rules per project type (SaaS, creative, game, book, automation, website, enterprise). New rules are promoted only after a test.

Safety first

Nothing risky happens without you.

Studio never deploys, deletes or sends messages on its own. It pauses, shows what it wants to do, and waits.

  • You can stop a run at any point and pick it up later
  • Secrets never written into specs or logs
  • Runs on your machine, your code stays with you
  • Every step has a run record you can read

Straight talk

What Studio is, and is not.

Studio is

  • A project manager layer on top of Claude Code
  • Plans, task graphs, checks, approvals and checkpoints
  • Local first, with a simple browser view

Studio is not

  • A replacement for Claude Code
  • A promise of finished, production-ready software without your review
  • Finished: browser inspection, deploy and launch automation are still in progress

FAQ

Questions.

Do I need Claude Code?

Yes. Studio uses Claude Code as its engine, so you need it installed and your own Claude access. Studio does not include a Claude subscription.

Does my code leave my computer?

Studio runs locally and keeps projects in folders on your machine. Claude Code itself talks to Anthropic as it normally does.

What does it cost?

Studio will be a monthly subscription. You also need your own Claude Code subscription, which is separate and paid to Anthropic. Nothing else is charged.

Can a non-programmer use it?

That is the goal, but the beta is built for developers and technical founders first. A non-technical experience comes later, once the engine is proven.

How is it different from Token Zombie?

Token Zombie trims Claude Code token waste. Studio manages a whole project from idea to delivery. They are separate tools.
