# tz-model-choice
Own wording from a Fable 5.2 usage video (claims unverified). Full version: TZ Studio `model-choice`.
1. Start cheap; raise effort before raising the model.
2. Big model plans/checks; Sonnet/Haiku build, search and read.
3. Set a low subagent model so Explore does not run at top price (confirm setting name).
4. Top model only for the biggest, hardest or 3D jobs, and only on the owner's request.
5. Clear brief, fresh session per task. Works on any model; re-check price-based rules when prices change.
