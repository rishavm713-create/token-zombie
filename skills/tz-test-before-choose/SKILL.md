# test-before-choose
Idea source: interview with the Vercel CEO on working with AI agents (2026), as summarised in a pasted list of 7 tips. Own wording.
1. Write the pass condition in one line before trying anything.
2. Build the smallest trial (MVP slice, one real task per candidate), same input for every candidate.
3. A fresh agent with no build context runs the trial from scratch and reports pass/fail with evidence.
4. Choose by the result, not by vibes or a prompting guide. Record the winner and why in the handoff.
