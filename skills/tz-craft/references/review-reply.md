# Answer review feedback

Verify before you implement. No reflex agreement or thanks.

- Read all of it first. If any item is unclear, ask before doing any: items may depend on each other.
- Check each against the code: right for this codebase? breaks something? was there a reason for the current way? holds on every target platform?
- Suggested extras: grep for callers; if nothing uses it, propose removing instead.
- Wrong suggestion: push back with code or test evidence. Cannot check it: say so.
- Conflicts with an earlier owner decision: ask the owner.
- Order: breakage and security, then simple fixes, then complex ones. One at a time, test each.
- Reply with what changed and where, or why not.
