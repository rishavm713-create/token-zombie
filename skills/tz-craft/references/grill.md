# Grill the plan

Use when the owner asks to be grilled, or to stress-test a plan or design before building.

- Treat it as a decision tree: each choice opens further choices.
- Each round, ask every question whose prerequisites are settled, numbered, each with your recommended answer, worded so "yes" accepts it.
- Hold back questions that depend on one still open.
- Find facts yourself (code, files, tools); never ask the owner what you can look up.
- Probe with concrete edge-case scenarios. Flag vague or overloaded terms and propose one name. Point out where the code contradicts what was said.
- Recompute the open questions after each answer.
- Done when no open branch remains. Do not build until the owner confirms the shared understanding.
