# Shape a vague idea

For "I want to build X" before there is a plan. Stress-testing an existing plan is a different job.

- Say what you already know; read the project before asking anything it can answer.
- Learn why it is wanted and how success looks before discussing how.
- Ask one specific question at a time, in the owner's words.
- Offer two or three approaches with trade-offs and your pick.
- Say every default out loud; an unheard default cannot be rejected. Cut features nobody asked for.
- Unsure it can work: try a throwaway spike.
- Play the design back in a few lines and get a yes before building. Size it: small goes straight to work, large is split, write the design down.
